## Overview

**HZ Hardware** is a responsive marketing site for a hardware and paint retailer. It presents product categories, featured items, a dedicated paint showcase, and services on one polished landing page — with a sticky mobile bottom bar and a floating WhatsApp button so customers can enquire without friction.

## ✨ Highlights

- 🛒 **Product categories & featured products** to surface the catalogue fast
- 🎨 **Paint showcase** section dedicated to the paint range
- 🧰 **Services** block explaining what the store offers beyond retail
- ⭐ **Why Choose Us + testimonials** for trust-building
- 📱 **Mobile bottom bar** and **floating WhatsApp button** for mobile-first conversions
- 📐 **Responsive, component-driven** layout

## 🧱 Tech Stack

- **React 18 + TypeScript** on **Vite**
- **Tailwind-style utility CSS** with MUI + Radix UI primitives

## 🚀 Getting Started

```bash
npm install     # install dependencies
npm run dev     # start the dev server
npm run build   # production build
```

## 🗂️ Structure

```
src/app/

│                 # Services, WhyChooseUs, Testimonials, About, Contact, Footer,
│                 # MobileBottomBar, WhatsAppButton
└── App.tsx       # composes the storefront
```
